# Android dge

Файловый менеджер для Android с редактором текста и lua, просмотром ZIP/APK,
списком приложений и сборкой APK прямо на телефоне.

## Что умеет
- Файлы: просмотр, копирование, удаление, создание файлов и папок
- Редактор текста и lua с сохранением
- ZIP: просмотр и распаковка, APK: установка и «Открыть как ZIP»
- Папка → APK (упаковка и подпись)
- Сборка проектов на телефоне (экспериментально)
